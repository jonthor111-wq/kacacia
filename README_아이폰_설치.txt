Fire Detector Offline PWA — iPhone 설치

1. ZIP 안의 파일을 HTTPS 정적 웹서버에 그대로 업로드합니다.
2. iPhone Safari에서 사이트를 엽니다.
3. 공유 → 홈 화면에 추가
4. 홈 화면의 Fire Detector 앱을 한 번 실행
5. 이후 인터넷 없이 사용 가능

이번 버전의 화면 개선:
- 현재 월/남은 항목을 가장 크게 표시
- 구역(Area)별로 자동 묶음
- 각 구역별 완료 수 표시
- OK/NG/N/A 상태를 카드 왼쪽 색으로 즉시 구분
- Remarks는 필요할 때만 펼침
- '다음 미점검' 버튼으로 현장 이동 중 바로 다음 항목 확인
- 미점검 / NG 필터
- 검색
- 월별/전체 CSV 내보내기
- IndexedDB 오프라인 저장
